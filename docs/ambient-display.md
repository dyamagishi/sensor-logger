# iPad常時表示

- 横置きの1画面表示。現在値（全センサー・直近24時間の小グラフ付き）30分 → 時計20秒 → 直近7日間の推移20秒で巡回。
- 24時間の履歴は1分ごと、7日間の履歴は5分ごとに取得。7日間はセンサーごとに順次取得し、取得失敗時は前回の記録を残す。本体のみ・取得済み記録である場合は推移画面に注記する。
- 切り替えは約0.4秒の横スライド。OSの「視差効果を減らす」に対応するブラウザ設定ではアニメーションを省略。
- 左右スワイプまたは画面下のボタンで切り替え。余白をタップすると現在値へ戻る。
- センサーをタップすると詳細履歴。「照明・設定」からHue操作、センサー追加、グラフ選択、電池・通信・保存状態を確認できる。
- 操作中・ダイアログ表示中・タブ非表示中は自動巡回を停止。無操作2分後に、その画面の表示時間を改めて開始する。
- 日本時間の0:00〜7:00は、内容を変えず暗い配色にする。
- CO₂ 1,500ppm以上で換気の目安を表示。最終受信から180秒以上経過したセンサー、API接続失敗も全画面で通知。古い値は削除せず最終値として残す。音・点滅なし。

## 輝度・画面保護

WebページからiPadの照度センサーやバックライト輝度は操作できない。環境光連動はiPad側の「設定 → アクセシビリティ → 画面表示とテキストサイズ → 明るさの自動調節」を有効にする。

夜間配色はページの色を暗くするもので、バックライトの減光・消灯ではない。画面の巡回は残像・消耗の防止を保証しない。不要な高輝度を避け、必要なら端末側の自動ロック等も利用する。本変更はスリープ抑止を追加しない。
